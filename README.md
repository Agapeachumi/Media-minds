# Media Minds Website

A clean responsive starter website for Media Minds.

## Included
- Home
- About
- Courses: Photography, Videography, Editing, AI
- Gallery
- Contact Us with Mediamindsdmp@gmail.com
- Officials Portal starter
- Responsive mobile layout

## Important security note
The Officials Portal is intentionally prepared for Supabase Authentication and Storage. Do not put real usernames/passwords in HTML or JavaScript. The next step is connecting Supabase Auth, a Storage bucket, and Row Level Security policies.

## Local preview
Open `index.html` in a browser.

## Deployment
Upload the project to a GitHub repository or deploy it to a static host such as Vercel/Netlify/GitHub Pages.
